# Executive Summary

A synthetic retail-bank onboarding process was evaluated using Lean Six Sigma DMAIC. The clean baseline contains 98,600 records after an independently validated data-quality pipeline. Quality-at-source is the strongest opportunity: First Pass Yield is **65.0%** and rework is **22.0%**. Median time to activation is **3.43 h** with a **5.82 h** P90.

The measurement-system study achieved **87.7%** agreement to reference and κ **0.681**, demonstrating usable but imperfect synthetic classification consistency. Root-cause analysis combines Pareto, rank-based tests, FMEA and regression; regression VIF remains controlled at **3.25** maximum.

A separate randomized 2³ factorial experiment tested staffing capacity, document pre-validation and routing strategy. The selected synthetic configuration was used in a 20,000-case pilot simulation. Median activation time changed from **3.44 h to 2.35 h**, rework from **22.3% to 11.0%**, and simulated COPQ/application from **R18.66 to R8.96**. A 26-week synthetic control period retained the lower median with one intentionally seeded control signal.

Required-control appraisal cost is separated from COPQ, so the project does not pretend that legitimate KYC review is a process defect. All figures are synthetic and should be interpreted as portfolio evidence of methodology, not workplace savings.
