# Hypothesis Testing

All tests use the synthetic clean dataset. Non-normal cycle-time distributions motivate rank-based tests.

- Manual review vs no review: Mann–Whitney p=0, rank-biserial effect=0.998; medians 12.59 h vs 3.35 h. This is an **association**, not a causal estimate.
- Channel cycle-time differences: Kruskal–Wallis p=1.75e-214.
- Rework by channel: chi-square p=1.74e-51.
