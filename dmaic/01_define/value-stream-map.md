# Value Stream View

Active verification/validation/review is treated as business/value-added assessment work for this portfolio. Queue, batch wait and rework are non-value-added. Baseline Process Cycle Efficiency is **34.3%**.

TIMWOODS hypotheses supported by the synthetic process include Waiting (queue/batch/reviewer wait), Defects (defined opportunity failures), Overprocessing (repeat processing after defects) and under-utilized capacity/skills during uneven branch-shift demand.
