# CTQ Tree

- **Fast onboarding** → time to activation → tiered SLA utilization / P90.
- **Right first time** → First Pass Yield → defect opportunities / rework.
- **Reliable process** → stable backlog and cycle time → SPC signals.
- **Efficient quality** → failure-related COPQ → internal/external failure cost.
- **Control integrity** → required review preserved → appraisal cost reported separately.
