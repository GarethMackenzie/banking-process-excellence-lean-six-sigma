# Project Charter

**Problem:** The synthetic onboarding baseline has First Pass Yield of **65.0%** and rework of **22.0%**, creating avoidable processing and failure cost despite high aggregate SLA compliance.

**Goal:** Test whether document pre-validation, capacity and routing changes can reduce rework and activation-time variation while preserving required KYC controls. No target improvement is hardcoded; the synthetic DOE/pilot determines observed effects.

**Scope:** Application receipt through activation or abandonment. Customer acquisition strategy and downstream account servicing are out of scope.

**Primary CTQs:** First Pass Yield, rework rate, time to activation, SLA utilization, COPQ/application.
